# Uniflow

**Uniflow** — персональный навигатор поступления для учеников 10–11 классов Казахстана. Сервис превращает профиль абитуриента в объяснимый выбор программ и конкретный план действий.

> Profile → Diagnosis → Match → Why → Compare → Roadmap → Next action → Progress

Проект создан для Case 02 «Персональный маршрут поступления» на LOCUS Startup Hackathon 2026.

**Live demo:** https://uniflow-admission-route.vercel.app

## Проблема

Информация о поступлении распределена между сайтами университетов, PDF и страницами приёмных комиссий. Абитуриент видит требования, но не понимает:

- какие программы подходят именно ему;
- почему один вариант лучше другого;
- какой пробел важнее закрыть сейчас;
- что делать следующим шагом.

## Решение

Uniflow проводит пользователя через короткую анкету, диагностирует профиль, ранжирует образовательные программы, показывает причины и ограничения, помогает сравнить варианты и создаёт персональный roadmap.

Основные возможности:

- анкета из пяти компактных этапов;
- диагностика сильных сторон и ограничений;
- минимум три диверсифицированные рекомендации;
- объяснимый балл совместимости по шести критериям;
- сравнение двух программ;
- выбор целевой программы;
- персональный roadmap и одно выделенное следующее действие;
- отметка прогресса;
- пересчёт после изменения бюджета, направления, города или экзаменов;
- сохранение профиля и прогресса в `localStorage`;
- адаптивный интерфейс без обязательной регистрации.

## Целевая аудитория

Ученик 10–11 класса или недавний выпускник из Казахстана, который планирует поступать на бакалавриат в 2027–2028 году на одно из IT-направлений:

- Computer Science;
- Data Science & AI;
- Software Engineering;
- Cybersecurity.

## Архитектура

```text
Student profile
      │
      ▼
Deterministic matching engine
      │
      ├── Academic fit
      ├── Program fit
      ├── Budget fit
      ├── Language fit
      ├── Location fit
      └── Preference fit
      │
      ▼
Ranked and diversified matches
      │
      ├── Human-readable reasons and gaps
      ├── Comparison
      └── Personalized roadmap
                 │
                 ▼
       localStorage progress
```

Проект намеренно не зависит от сложного backend: основной сценарий остаётся доступным даже при проблемах с внешними сервисами.

## Matching algorithm

Итоговый балл — **совместимость профиля**, а не вероятность поступления.

| Критерий | Вес |
| --- | ---: |
| Академическое соответствие | 25% |
| Соответствие направления | 25% |
| Бюджет | 20% |
| Язык обучения | 10% |
| Локация | 10% |
| Личные приоритеты | 10% |

Для каждого результата сохраняется полный breakdown. Причины формируются из тех же структурированных данных, которые использовались при расчёте. Программы диверсифицируются по университетам, чтобы четыре верхние карточки не представляли один и тот же вуз.

## Данные и проверяемость

Каждая карточка содержит официальный источник и статус цены:

- `Проверено` — опубликовано университетом для указанного учебного года;
- `Прошлый год` — официальное значение требует обновления перед подачей;
- `Демо-оценка` — используется только для демонстрации логики и не представляется официальным фактом.

Основные источники:

- [Astana IT University — Bachelor’s Degree](https://astanait.edu.kz/en/bachelor)
- [Astana IT University — Computer Science](https://astanait.edu.kz/Computer-Science-bachelor)
- [IITU — Бакалавриат](https://iitu.edu.kz/ru/applicants/bachelor/)
- [KBTU — School of Information Technology and Engineering](https://kbtu.edu.kz/ru/shkoly/shkola-informatsionnykh-tekhnologij-i-inzhenerii/bakalavriat-shkoly-informatsionnykh-tekhnologij)
- [SDU University — Admission](https://sdu.edu.kz/en/admission-3-2/)
- [Nazarbayev University — Regular Admissions](https://nu.edu.kz/admissions/how-to-apply/foundation-undergraduate/regular-admissions/)
- [Satbayev University — tuition PDF 2025–2026](https://official.satbayev.university/download/document/47247/Tuition%20Fees%20for%20Bachelor%27s%20Programs%20for%20Legal%20Entities%20for%20the%202025%EF%BF%BD2026.pdf)

Официальные сроки приёма на 2027 год ещё не опубликованы. Поэтому roadmap явно разделяет личные сроки подготовки и даты, которые необходимо перепроверить на сайте университета. Сервис не генерирует неподтверждённые дедлайны.

## AI и автоматизация

В текущей версии используется объяснимый rule-based recommender — этот подход прямо разрешён условиями Case 02. Он выполняет функции интеллектуальной системы поддержки решений:

1. нормализует ограничения профиля;
2. вычисляет многокритериальное соответствие;
3. выявляет сильные стороны и пробелы;
4. перестраивает рекомендации при изменении вводных;
5. генерирует roadmap из требований целевой программы.

Внешний LLM не является критической зависимостью. Его можно подключить позднее для перефразирования объяснений, сохранив факты и ranking за детерминированным движком.

При разработке использовался OpenAI Codex как AI-инструмент для анализа требований, написания кода и проверки проекта.

## Локальный запуск

Требования: Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

Production-проверка:

```bash
npm run lint
npm run build
npm run start
```

Browser smoke test (при запущенном приложении на порту `4173`):

```bash
npm run dev -- --hostname 127.0.0.1 --port 4173
npm run test:smoke
```

Переменные окружения для текущей версии не требуются. Секреты нельзя добавлять в репозиторий; `.env*` внесены в `.gitignore`.

## Judge demo scenario

Быстрый путь:

1. Открыть главную страницу.
2. Нажать «Посмотреть демо».
3. Изучить диагностику профиля.
4. Раскрыть «Подробнее о мэтче» у первой рекомендации.
5. Проверить breakdown и официальный источник.
6. Открыть сравнение и выбрать два варианта.
7. Выбрать целевую программу.
8. Открыть roadmap.
9. Отметить первое действие выполненным.
10. Нажать «Изменить профиль».
11. Поменять направление `Data Science & AI` на `Cybersecurity` или бюджет с 2,5 млн до 1,5 млн ₸.
12. Завершить анкету и увидеть пересчитанные рекомендации, объяснения и маршрут.

Полный путь можно проверить через кнопку «Построить мой маршрут» без использования демо-профиля.

## Стабильность и fallback

- основной сценарий работает без сети после загрузки приложения;
- прогресс сохраняется локально;
- отсутствие IELTS/ЕНТ не блокирует рекомендации, а создаёт задачу в roadmap;
- неизвестные сроки отмечаются как требующие проверки;
- продукт не показывает гарантии или вымышленные проценты поступления.

## Известные ограничения

- датасет сфокусирован на IT-программах Казахстана;
- часть стоимости требует перепроверки и явно отмечена как демонстрационная или прошлогодняя;
- нет аккаунтов и синхронизации между устройствами;
- нет автоматического обновления данных с сайтов университетов;
- грантовая рекомендация является ориентиром подготовки, а не обещанием гранта;
- интерфейс первой версии русскоязычный, названия вузов и программ сохранены на английском.
